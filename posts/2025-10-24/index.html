Microsoft

Azure DevOps

Azure DevOps is a cloud-based, unified platform from Microsoft that provides an integrated suite of tools for software development teams, supporting the entire software development lifecycle from planning and collaboration to building, testing, and deployment.

KQL

Kusto Query Language (KQL) is a powerful tool for exploring your data and discovering patterns, identifying anomalies and outliers, creating statistical modeling, and more.

Artificial Intelligence

Prompt Injection

A prompt injection is a cybersecurity attack where an adversary manipulates the input prompt in a large language model (LLM) to override intended instructions and induce unintended, often malicious, behavior.

LTX-2

LTX-2 is a next-generation, open-source AI video foundation model developed by Lightricks, designed as a complete creative engine for professional video production workflows.

Warmwind OS

Warmwind OS is a cloud-native, AI-driven platform designed to function as an operating system that automates digital workflows by acting like a “digital employee”

Deta Surf

Deta Surf is an open-source, AI-powered notebook and browser hybrid designed to enhance research, note-taking, and knowledge management by integrating web content, files, and media into a single, personal workspace.

Data Engineering

OpenDbt

OpenDbt is a fully open-source package built on top of dbt-core that extends its functionality by adding features not available in the standard open-source version of dbt, which operates on an open-core model

dlt

dlt is an open-source, Python-first library designed to simplify the creation and maintenance of data pipelines by automating the Extract and Load (E and L) phases of ELT processes

Software

imessage-exporter

imessage-exporter is a free, open-source command-line tool developed by ReagentX that allows users to export their iMessage, SMS, and MMS conversation data from Apple devices

Other

Ladybird

Ladybird is an open-source, independent web browser project developed by the Ladybird Browser Initiative, a nonprofit organization focused on creating a browser from scratch without relying on existing engines like Chromium, WebKit, or Gecko.

OpenMetadata

OpenMetadata is an open-source, unified metadata platform designed for data discovery, data observability, and data governance, powered by a central metadata repository, detailed column-level lineage, and seamless team collaboration.

Credly

Credly is a global digital credentialing platform that enables organizations to issue, manage, and verify digital badges, which represent skills, achievements, and learning outcomes.
