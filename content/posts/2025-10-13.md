## Software

### OpenSpec 

> [OpenSpec](https://github.com/Fission-AI/OpenSpec) is an open-source lightweight spec-driven framework for AI coding assistants

### Penpot 

> [Penpot](https://penpot.app/) is a free and open-source design and prototyping tool built with web standards, supporting collaboration between designers and developers.

### Requestly 

> [Requestly](https://requestly.com) is an open-source frontend development platform that acts as a local proxy, enabling developers to intercept, modify, and debug network traffic in real time.

## Design

### Hero Patterns

> [Hero Patterns](https://heropatterns.com) is a collection of repeatable SVG background patterns for you to use on your web projects.

### Zondicons

> [Zondicons](https://www.zondicons.com) is a set of free premium SVG icons for you to use on your digital products.


### Heroicons

> [Heroicons](https://heroicons.com/outline) is a set of free MIT-licensed high-quality SVG icons for UI development.

### Loading

> [Loading](https://loading.io) is an online platform that enables users to create and customize animated loading icons, spinners, and other visual effects for websites and applications


### BGJar

> [BGJar](https://bgjar.com) is a free svg background generator for your websites, blogs and app.
