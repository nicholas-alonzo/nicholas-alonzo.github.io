## Database

### [Atlas](https://atlasgo.io/)

> Atlas is a language-agnostic tool for managing and migrating database schemas using modern DevOps principles.

### [Delta Lake](https://delta.io)

> Delta Lake is an open-source storage framework that enables building a format agnostic Lakehouse architecture with compute engines including Spark, PrestoDB, Flink, Trino, Hive, Snowflake, Google BigQuery, Athena, Redshift, Databricks, Azure Fabric and APIs for Scala, Java, Rust, and Python.

## Design

### [Affinity](https://www.affinity.studio)

> Affinity is a all-in-one professional design application that integrates photo editing, vector illustration, and page layout tools into a single platform. It is available for free on Windows and Mac.

### [Graphite](https://graphite.rs)

> Graphite is a free, open-source vector and raster graphics editor currently available in alpha, designed to provide a fully nondestructive editing workflow by combining layer-based compositing with a node-based procedural design engine.

## Utilities

### [Cyberduck](https://cyberduck.io/)

> Cyberduck is an open-source, libre server and cloud storage browser designed for macOS and Windows, with support for the command-line interface (CLI) available on Linux as well. It functions as an FTP client supporting protocols such as FTP, SFTP, WebDAV, and FTP/TLS, enabling secure file transfers over encrypted connections.

### [Postal](https://postalserver.io/)

> Postal is a complete and fully featured mail server for use by websites & web servers. Think Sendgrid, Mailgun or Postmark but open source and ready for you to run on your own servers.

### [Mautic](https://mautic.org)

> Mautic is an open-source marketing automation platform designed to help businesses manage, automate, and optimize their marketing campaigns across multiple channels.

### [Plunk](https://www.useplunk.com)

> Plunk is an open-source email platform built on top of AWS SES. It allows you to easily send emails from your applications. It can be considered as a self-hosted alternative to services like SendGrid, Resend or Mailgun.

### [useSend](https://usesend.com)

> useSend is an open-source email platform designed as an affordable alternative to traditional email services like Mailchimp, Brevo, Klaviyo, Resend, SendGrid, Mailgun, and Postmark. It is built on Amazon SES infrastructure, providing a reliable and cost-effective way to send transactional, marketing, and product emails.

### [SendPortal](https://sendportal.io)

> SendPortal is an open-source, self-hosted email marketing platform designed to give businesses and agencies full control over their email campaigns and data. It functions as a user-friendly control panel (GUI) that integrates with third-party email service providers like Mailgun, Mailjet, SendGrid, and Amazon SES to handle the actual delivery of emails.

## Hosting

### [PikaPods](https://www.pikapods.com/)

> PikaPods is a managed cloud hosting platform designed to simplify the deployment and management of open-source web applications.

## Python Development

### [Pydantic](https://docs.pydantic.dev/latest/)

Pydantic is a Python library designed for data validation and settings management, leveraging Python's type hints to enforce data types and structures at runtime. It allows developers to define data models using Python classes with annotated fields, automatically validating and converting input data to ensure it conforms to the expected types and constraints.
