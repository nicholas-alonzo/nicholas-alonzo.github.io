## Artificial Intelligence

### AGENTS.md

> [AGENTS.md](https://agents.md) is a simple, open format designed to provide clear, structured instructions for AI coding agents to understand and work on a software project. It serves as a "README for machines," offering machine-readable guidance that complements human-focused documentation like README.md.

### SKILL.md

> [SKILL.md](https://docs.claude.com/en/docs/claude-code/skills) is a framework developed by Anthropic for extending the capabilities of its Claude AI models by packaging procedural knowledge, instructions, scripts, and resources into reusable, self-contained units.

### Claude Code on the Web

> Claude Code on the web lets you kick off coding sessions without opening your terminal. Connect your GitHub repositories, describe what you need, and Claude handles the implementation.  
>
> Each session runs in its own isolated environment with real-time progress tracking, and you can actively steer Claude to adjust course as it’s working through tasks.

Read more [here](https://www.anthropic.com/news/claude-code-on-the-web)

### LocalAI

> [LocalAI](https://localai.io) is a free, open-source, community-driven project designed as a drop-in replacement for commercial AI services like OpenAI and Anthropic, enabling users to run large language models (LLMs), generate images, audio, and video, and perform other AI tasks locally on consumer-grade hardware without requiring a GPU.

## Software

### BentoPDF

> [BentoPDF](https://bentopdf.com) is a privacy-first, client-side PDF toolkit that enables users to manipulate, edit, merge, and process PDF files directly within their web browser without uploading files to any server

### CommonForms

> [CommonForms](https://github.com/jbarrow/commonforms) is a project focused on developing open models to automatically detect form fields in PDFs
