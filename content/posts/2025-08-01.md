I've learned about so many new things since my last post.

Recently, I bought some accessories for my Raspberry Pi 5 I had bought back in March. My goal had been turn the RPi into a mini-homelab using CasaOS and have then come across various projects. Below are some apps to highlight.

## ConvertX

> [ConvertX](https://github.com/C4illin/ConvertX) is a self-hosted online file converter. Supports over a thousand different formats. Written with TypeScript, Bun and Elysia.

## Karakeep

> [Karakeep](https://karakeep.app/) is a self-hostable bookmark-everything app (links, notes and images) with AI-based automatic tagging and full text search

## Nginx Proxy Manager

> [Nginx Proxy Manager](https://nginxproxymanager.com/) is a simple, powerful tool to help you host multiple websites on a single server.

## RomM

> [RomM](https://romm.app/) is a self-hosted rom manager. Scan, enrich, and browse your game collection with a clean and responsive interface. <br><br> With support for multiple platforms, various naming schemes and custom tags, RomM is a must-have for anyone who plays on emulators.

## Pinchflat

> [Pinchflat](https://github.com/kieraneglin/pinchflat) is a self-hosted app for downloading YouTube content built using yt-dlp. It's designed to be lightweight, self-contained, and easy to use. You set up rules for how to download content from YouTube channels or playlists and it'll do the rest, periodically checking for new content. It's perfect for people who want to download content for use in with a media center app (Plex, Jellyfin, Kodi) or for those who want to archive media!

## Feather

> [Feather](https://feathericons.com/) is a collection of simply beautiful open-source icons. Each icon is designed on a 24x24 grid with an emphasis on simplicity, consistency, and flexibility.

## Noun Project

> [Noun Project](https://thenounproject.com/) is the World's Most Diverse and Extensive Collection of Free Icons and Mission-Driven Stock Photos.

## Tabler

> [Tabler](https://tabler.io/admin-template) is a free and open-source HTML Dashboard UI Kit built on Bootstrap and offers a set of free MIT-licensed high-quality SVG icons for you to use in your web projects. Each icon is designed on a 24x24 grid and a 2px stroke.

## IconPacks

> [IconPacks](https://www.iconpacks.net/): Free SVG vector, PNG icons, symbols and icon packs for commercial and personal use. High-quality transparent SVG, PNG icons for apps, website designs, slides, presentations, printing and more. Customize every free icons with online icon editor and download for free.

## v0

> [v0](https://v0.dev/) turns your ideas into real web apps, no coding required. Describe what you want with natural language, and v0 builds it for you using modern frontend tools. By removing the technical barriers to web development, anyone can go from concept to working software in minutes.

## Proton Authenticator

> [Proton Authenticator](https://proton.me/authenticator) is a free, open-source, and secure two-factor authentication (2FA) app developed by Proton. It allows users to generate time-based one-time passwords (TOTPs) for securing their online accounts.

## NiceGUI

> [NiceGUI](https://github.com/zauberzeug/nicegui) is an easy-to-use, Python-based UI framework, which shows up in your web browser. You can create buttons, dialogs, Markdown, 3D scenes, plots and much more.<br><br>It is great for micro web apps, dashboards, robotics projects, smart home solutions and similar use cases. You can also use it in development, for example when tweaking/configuring a machine learning algorithm or tuning motor controllers.
