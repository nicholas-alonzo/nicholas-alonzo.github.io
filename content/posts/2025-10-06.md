## Blazor Diagrams

> [Blazor Diagrams](https://blazor-diagrams.zhaytam.com/) is a library for creating interactive diagrams and flowcharts in Blazor applications, enabling developers to visualize data and processes dynamically.

## what3words

> [what3words](https://what3words.com) is a global addressing system that divides the world into 3-word combinations, making it easier to communicate precise locations, especially in areas without traditional street addresses.

## Teachable Machine

> [Teachable Machine](https://teachablemachine.withgoogle.com) is a web-based tool by Google that allows users to train machine learning models using simple inputs like images, sounds, or text, making AI accessible to non-experts.

## Coolify

> [Coolify](https://coolify.io) is an open-source and self-hostable platform designed as an alternative to cloud-based services like Vercel, Heroku, Netlify, and Railway. It simplifies deploying and managing web applications, offering features like one-click deployment, auto-scaling, and integrated databases for developers and teams.

## StaticDeploy

> [StaticDeploy](https://staticdeploy.io) is an open-source platform designed for deploying and managing static web applications and websites. It automates the deployment of static websites, providing seamless integration with version control systems and continuous deployment pipelines for efficient web development workflows.
