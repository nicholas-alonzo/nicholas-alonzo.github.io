Wow, the last time I posted was back at the start of August - I had lots going on since then, but have still been keeping up with new things as usual

## Homelab

### Netbird

> [NetBird](https://netbird.io/) is an open-source platform that combines a configuration-free peer-to-peer private network with centralized access control, creating a unified system for building secure private networks for organizations or home use

### Gitea

> [Gitea](https://about.gitea.com/) is a lightweight, open-source, self-hosted software development platform designed to provide a comprehensive suite of tools for managing software projects using Git

### Actual Budget

> [Actual Budget](https://actualbudget.org/) is a fast, privacy-focused personal finance management application that utilizes the envelope budgeting methodology, where budgets are based on real, available income rather than projected figures


## Privacy

### PrivacyPack

> [PrivacyPack](https://privacypack.org/) is a tool designed to help users showcase their transition from mainstream privacy-invasive apps to privacy-respecting alternatives


## Data

### Microsoft Fabric

> [Microsoft Fabric](https://learn.microsoft.com/en-us/fabric/fundamentals/microsoft-fabric-overview) is a unified, cloud-based, Software as a Service (SaaS) platform designed to simplify data management, analytics, and AI integration for organizations of all sizes


### Data Engineering Wiki

> [Data Engineering Wiki](https://dataengineering.wiki/Index) is an open-source living document that contains a constantly evolving collection of topics related to data engineering

### Orbital

> [Orbital](https://posit.co/blog/introducing-orbital-for-scikit-learn-pipelines/) Convert SKLearn pipelines into SQL queries for execution in a database without the need for a Python environment.

## Artificial Intelligence

### MCP

> [Model Context Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro) is an open-source standard to provide a universal language for AI systems to communicate with external data sources, tools, and services

### Kineto

> [Kineto](https://kineto.dev/) is an AI-powered, no-code platform developed by JetBrains that enables users to create websites and web applications without writing any code

### Kilo Code

> [Kilo Code](https://kilocode.ai/) is an open-source AI agent extension for Visual Studio Code designed to enhance coding efficiency by generating code, automating tasks, and providing intelligent suggestions


### Context Engineering

> [Context Engineering](https://www.datacamp.com/blog/context-engineering) is the discipline of designing and building dynamic systems that provide an LLM with all the necessary information, tools, and instructions in the right format and at the right time to accomplish a task effectively

## Software

### File Pilot

> [File Pilot](https://filepilot.tech/) is a next-generation file explorer designed for Windows, built from scratch for light-speed performance and featuring a modern, customizable interface


### Carbon

> [Carbon](https://docs.carbon-lang.dev/) is an experimental, open-source programming language developed by Google as a potential successor to C++
