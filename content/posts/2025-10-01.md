## Software

### DataGrip Non-Commercial License

> If you’re using DataGrip for non-commercial purposes, such as learning, hobby or open-source project development, or content creation, you can now do so for free. Read more about it [here](https://blog.jetbrains.com/datagrip/2025/10/01/datagrip-is-now-free-for-non-commercial-use/).

I am a huge fan of DataGrip and now being able to use this for non-commercial purposes is a game changer. I think other Database IDEs like DBeaver are going to have users now migrate over to DataGrip

## Self Hosting

### HexOS: Q3 Update

> New Apps Curation Process, Jellyfin/Home Assistant/qBittorrent Apps, Folder Wizard. Read more about it [here](https://docs.hexos.com/release-notes/command-deck/2025-09-29.html).

This is exciting to see - I supported this project by buying multiple licenses when I heard about it so it's nice to know progress is being made towards version 1.0. Once that happens I'll be putting some effort into making a NAS to store lots of data I have scattered across devices.

## Artificial Intelligence

### Ask Brave

> Ask Brave is a single interface that consolidates search and AI chat. Read more about it [here](https://brave.com/blog/ask-brave/).

Brave has become one of my favorite tools as a browser and search engine. It has gotten so much better that I don't rely on Google as much anymore. I've already tested it out and results look great.
