## Data Visualization & Analytics

### [Streamlit](https://streamlit.io)

> Streamlit is an open-source Python library that allows data scientists and developers to create interactive web apps for data visualization and machine learning with minimal effort.

### [Evidence](https://evidence.dev)

> Evidence is a data documentation and visualization tool that allows teams to create live data docs using SQL and Markdown, turning queries into interactive reports and dashboards.

### [Sigma](https://www.sigmacomputing.com)

> Sigma is a cloud-native analytics platform that enables business analysts and data teams to explore, analyze, and visualize large datasets using a spreadsheet-like interface.

## Data Engineering & Integration

### [mssql-python](https://github.com/microsoft/mssql-python)

> mssql-python is the official Microsoft Python Driver for SQL Server, Azure SQL, and SQL databases in Fabric.

### [Artie Transfer](https://github.com/artie-labs/transfer)

> Artie Transfer is an open-source tool designed to streamline data integration and transformation workflows, particularly for syncing data between databases and data warehouses.

### [DataKit](https://datakit.studio)

> DataKit is a modern data development environment that helps data teams build, test, and deploy data pipelines with integrated tooling and collaboration features.

## Software Development & Infrastructure

### [Fly.io](https://fly.io)

> Fly.io is a platform that allows developers to deploy and run applications globally on a distributed cloud infrastructure with low latency and high availability.

### [Ghostty](https://ghostty.org)

> Ghostty is a GPU-accelerated terminal emulator designed for speed, visual clarity, and modern developer workflows, offering high-performance rendering and customization.

### [Brave AI Browser](https://brave.com/blog/ai-browsing/)

> Brave AI Browser is a privacy-focused web browser with integrated AI features that assist users in summarizing content, answering questions, and enhancing browsing productivity.

## Enterprise Workflow & IT Automation

### [ServiceNow](https://www.servicenow.com)

> ServiceNow is a cloud-based platform that automates and streamlines enterprise workflows, including IT service management, customer service, and HR operations.
