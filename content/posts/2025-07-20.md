## FaaS

> [Function as a service (FaaS)](https://en.wikipedia.org/wiki/Function_as_a_service) is a cloud computing model that enables developers to create and run small, modular pieces of code, known as functions, in response to specific events or triggers.

## Web3Forms

> [Web3Forms](https://web3forms.com) is a simple tool to set up Contact Forms for Static Websites. Receive form submissions directly in your email inbox without any server or back-end code. 

I came across Web3Forms while looking up contact forms for static site and came across this awesome [article](https://dsavir-h.medium.com/contact-form-for-static-site-with-web3forms-575ee166732).
