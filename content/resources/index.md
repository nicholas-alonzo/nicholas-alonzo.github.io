Here's a list of resources focused on privacy, security, productivity, and tech in general

## Software & Tools

### AI

- [Amuse](https://www.amuse-ai.com/)

  > Amuse is an application developed by [TensorStack](https://www.tensorstack.ai) in collaboration with AMD, designed to generate images and videos using Stable Diffusion AI models on local hardware.

- [ComfyUI](https://www.comfy.org/)

  > ComfyUI lets you design and execute advanced stable diffusion pipelines using a graph/nodes/flowchart based interface.

- [HuggingFace](https://huggingface.co/)

  > Hugging Face is a company and platform where the machine learning community collaborates on models, datasets, and applications.

- [Ollama](https://ollama.com/)

  > Ollama is an open-source tool that allows you to run large language models (LLMs) directly on your local machine, providing greater control over data and privacy.

### Browser

- [Brave](https://brave.com/)

  > Brave is a free and open-source web browser that focuses on user privacy and security. It blocks ads and trackers by default, which helps to speed up page loading and improve the overall browsing experience.

- [Vivaldi](https://vivaldi.com/)

  > Vivaldi is a freeware, cross-platform web browser developed by Vivaldi Technologies, offering a highly customizable browsing experience with features like privacy controls, tab management, and a customizable interface.

### Email

- [ProtonMail](https://proton.me/mail)

  > ProtonMail is a secure, encrypted email service that prioritizes user privacy and offers end-to-end encryption for confidential communication.

- [SimpleLogin](https://simplelogin.io/)

  > SimpleLogin is an email aliasing tool that allows users to create anonymous email addresses for online sign-ups, protecting their real email from spammers and phishing attempts.

### IDE

- [DataGrip](https://www.jetbrains.com/datagrip/)

  > DataGrip is a database management tool for developers, designed to query, create, and manage databases across local, server, or cloud environments.

- [DBeaver](https://dbeaver.io/)

  > DBeaver is a free and open-source universal database management tool that allows users to connect to and work with various types of databases, including SQL, NoSQL, and cloud databases.

- [PyCharm](https://www.jetbrains.com/pycharm/)

  > PyCharm is designed specifically for Python programming, offering features like smart code completion, debugging tools, and support for web frameworks.

- [VSCodium](https://vscodium.com/)

  > VSCodium is a community-driven, freely-licensed binary distribution of Microsoft’s editor VS Code. It is based on the open-source code of Visual Studio Code (VS Code), but it removes telemetry and other proprietary components, making it a fully open-source alternative.


### Multifactor Authentication

- [2FAS](https://2fas.com/auth/)

  > 2FAS (Two-Factor Authentication Service) is a user authentication method that provides an additional layer of security for online accounts. In addition to a username and password, 2FAS uses a second factor, such as a one-time password (OTP) shown on a user's phone, to verify a user's identity. This helps prevent unauthorized access to accounts, even if a password is compromised.

- [Ente Auth](https://ente.io/auth/)

  > Ente Auth is a free, open-source, cross-platform, end-to-end encrypted authenticator app designed to securely store and generate Time-Based One-Time Password (TOTP) tokens for two-factor authentication (2FA).


### NAS

- [CasaOS](https://casaos.zimaspace.com/)

  > CasaOS is an open-source NAS (Network Attached Storage) operating system designed to simplify the setup and management of home servers, offering a user-friendly interface and support for containerized applications.

- [HexOS](https://hexos.com/)

  > HexOS is a user-friendly NAS operating system built on TrueNAS Scale, aiming to provide an easy-to-use alternative for managing storage, virtual machines, and applications while offering flexibility and control over hardware choices.

### Password Manager

- [KeePassXC](https://keepassxc.org/)

  > KeePassXC is a free, open-source password manager that allows users to store and manage their passwords securely, featuring browser integration, a built-in password generator, and support for key files for additional security.

- [Strongbox](https://strongboxsafe.com/)

  > Strongbox is a iOS & macOS password manager that focuses on secure storage of passwords protected by a master password, supporting open-source formats like Password Safe and KeePass.

### Video Editing

- [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve)

  > DaVinci Resolve is a powerful video editing software featuring advanced tools for cutting, trimming, and editing videos with a focus on speed and efficiency.

- [LosslessCut](https://mifi.no/losslesscut/)

  > LosslessCut is a free, multi-platform video editor that specializes in lossless trimming and cutting of video and audio files, allowing users to remove unwanted parts without re-encoding, thus preserving the original quality.

### Other

- [draw.io](https://www.drawio.com/)

  > draw.io is a free, online diagramming tool that allows users to create flowcharts, diagrams, mind maps, organisation charts, and more.

- [ImageOptim](https://imageoptim.com/)

  > ImageOptim is a free and open-source image optimization tool designed for macOS. It allows users to compress and optimize images without compromising their quality, making them more suitable for web use.

- [LocalSend](https://localsend.org/)

  > LocalSend is a free, open-source app that allows you to securely share files and messages with nearby devices over your local network without needing an internet connection.
